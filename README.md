# Pastel do Cowboy

Site institucional do Pastel do Cowboy, com cardápio organizado e caminhos para delivery ou retirada.

## Destaques

- Narrativa visual com efeitos de rolagem
- Cardápio real organizado por categorias
- Links oficiais para pedidos, WhatsApp, Instagram e localização
- Design responsivo para celular e desktop

## Publicação

O projeto é estático e usa a pasta `dist` como saída de produção. O arquivo `vercel.json` já está configurado para publicação na Vercel.
